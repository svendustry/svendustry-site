SEC 11
Reminders & Safety

NEVER paste tokens, passwords, or API keys into Claude chat. They become part of conversation context and remain exposed even if "deleted." Use secret-tool store and reference paths only.

NEVER run curl <url> | bash without verifying. Even from inside Odin under settings.json (b) — review what you're about to execute.

ALWAYS run openclaw backup create before destructive substrate ops. Backups land at ~/.openclaw-backup-<timestamp>/.

ALWAYS detach (Ctrl+b d) when done. Don't kill tmux unless you mean to end Odin's session.

If something feels wrong, don't fight it. Stop, audit, doctor, then ask before continuing.
